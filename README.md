# Cybersecurity Fundamentals

## Overview
This repository documents my understanding of fundamental cybersecurity principles, ethical hacking concepts and common cybersecurity threats.

The purpose of this project is to build a strong foundation in cybersecurity while developing the ability to identify, understand and explain potential security risks.

## Learning Objectives

- Understand the core principles of cybersecurity.
- Explore ethical hacking and different hacker classifications.
- Understand the CIA Triad.
- Identify common cybersecurity threats.
- Explain the potential impact of cyberattacks on organisations and systems.

## Topics Covered

### 1. Cybersecurity Fundamentals
Introduction to cybersecurity, its importance and the role of ethical hacking in identifying security weaknesses.

### 2. The CIA Triad
- Confidentiality
- Integrity
- Availability

### 3. Types of Hackers
- White Hat Hackers
- Black Hat Hackers
- Grey Hat Hackers

### 4. Common Cybersecurity Threats
- Malware
- Phishing
- Ransomware

### 5. Threat Analysis
Exploring how common cybersecurity threats affect individuals, businesses and IT infrastructure.

## Skills Developed

- Cybersecurity fundamentals
- Threat identification
- Security awareness
- Risk analysis
- Ethical hacking concepts
- Technical documentation

Completed as part of my ongoing cybersecurity learning journey.
